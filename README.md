# Personal Portfolio Website

A modern and responsive personal portfolio website built to showcase my skills, projects, internships, certifications, resume, and contact details.

## Live Website

[View Portfolio](https://nandithaportfolio.nandithabnanditha.workers.dev/)

## About

This portfolio is designed with a clean and professional layout to make it easy for recruiters to view my profile, technical skills, project work, and resume. The website is fully responsive and works on desktop, tablet, and mobile devices.

## Features

- Modern responsive design
- Smooth scroll and animations
- Profile section
- Skills section
- Projects section
- Internship and experience section
- Certifications section
- Resume download option
- Contact section
- Mobile-friendly layout

## Technologies Used

## How to Use

1. Clone the repository.
2. Open `index.html` in a browser.
3. Update the content, images, links, and resume as needed.
